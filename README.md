---

## 📖 Sobre o Projeto

Este projeto tem como objetivo testar a integração entre Python e o Stellarium, permitindo controlar o ambiente do planetário em tempo real.

Funcionalidades testadas:
- 🌍 Focar em corpos celestes  
- ⭐ Exibir constelações  

---

## 🎯 Objetivo

Criar uma base para:
- Apresentações interativas (planetário)  
- Automação de simulações astronômicas  

---

## ⚙️ Requisitos

- Python 3.x  
- Biblioteca `requests`  
- Stellarium instalado  
- Plugin **Remote Control** ativado  

---

## 🔧 Configuração do Stellarium

1. Abra o Stellarium  
2. Pressione `F2`  
3. Vá em **Complementos → Controle Remoto**  
4. Ative:
   - ✔ Carregar ao iniciar  
   - ✔ Ativar automaticamente ao iniciar  
5. Configure:
   - Porta: `8090`  
6. Salve e reinicie
